# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-31
### Added
- Initial scaffold with README, .gitignore, LICENSE, pubspec.
- Riverpod based `StellarAccountProvider` with state management and unit tests.
- Freighter integration service and widgets:
  - `StellarConnectButton`
  - `StellarAddressChip`
  - `StellarBalanceDisplay`
  - `StellarNetworkSwitcher`
  - `StellarSignRequestSheet`
- Example app demonstrating full flow (connect → balance → sign/pay).
- GitHub Actions workflow for running Flutter tests on push/PR.
- Issue backlog with roadmap items.
